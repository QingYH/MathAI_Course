强化学习与 Q-learning

当环境转移模型未知时，智能体依靠与环境交互获得的样本进行学习。本讲讨论无模型设定、蒙特卡洛与时序差分思想、动作价值估计、离策略机制与探索–利用权衡，掌握代表性无模型算法 Q-learning 及其收敛条件。

一、课程导入：试错中学会决策

例子 1：训练小狗做动作

我们并不提前告诉小狗“坐下”动作的内部机理，而是在它做对时给奖励、做错时不给。小狗通过一次次试错（trial and error），逐渐学会哪些动作更可能带来奖励。强化学习与此类似：智能体没有环境模型，只能从交互样本中改进决策。

例子 2：迷宫里摸索出口

机器人不知道迷宫的完整地图，只能走到一格、观察奖励、再选下一个动作。经过多轮尝试，它逐步记住“哪些状态–动作组合更有价值”，最终找到通往出口的路线。这正是无模型强化学习的直观图景。

与第二讲的区别：动态规划要求已知 $P(s'\mid s,a)$ 与 $R(s,a)$；无模型方法不显式重建模型，直接用样本轨迹 $(S_t,A_t,R_{t+1},S_{t+1})$ 估计价值。

三、数学原理

3.1 蒙特卡洛与时序差分

蒙特卡洛（MC）用一整局完整回报 $G_t$ 作为估计目标，无偏但方差高；时序差分（TD）用下一时刻的当前估计自举（bootstrapping）更新，方差较低但引入偏差。TD(0) 更新为：

$$V(S_t)\leftarrow V(S_t)+\alpha\big[R_{t+1}+\gamma V(S_{t+1})-V(S_t)\big]$$

3.2 动作价值与 Q-learning 更新

控制问题需要比较动作优劣，因此直接学习动作价值 $Q(s,a)$。Q-learning 以贝尔曼最优方程的样本形式为更新目标：

$$Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha\big[R_{t+1}+\gamma\max_{a'}Q(S_{t+1},a')-Q(S_t,A_t)\big]$$
$$\text{TD 误差：}\quad \delta_t=R_{t+1}+\gamma\max_{a'}Q(S_{t+1},a')-Q(S_t,A_t)$$

3.3 离策略：行为策略与目标策略分离

更新目标中对下一动作取 $\max$，对应贪心的目标策略；而实际采样所用的是带探索的行为策略。二者分离，正是 Q-learning 被称为离策略（off-policy）的原因：它可以在探索甚至他人遗留的数据上学习最优策略。

3.4 探索–利用与 ε-贪心

为避免过早锁定次优动作，行为策略常用 ε-贪心：以概率 $\varepsilon$ 随机探索，以概率 $1-\varepsilon$ 选择当前最优动作：

$$\pi(a\mid s)=\begin{cases}1-\varepsilon+\varepsilon/|\mathcal{A}|,&a=\arg\max_a Q(s,a)\\\varepsilon/|\mathcal{A}|,&\text{其他}\end{cases}$$

3.5 收敛条件

在以下条件下，Q-learning 依概率收敛到最优动作价值 $Q^{*}$（Watkins & Dayan, 1992）：

  • 奖励有界；
  • 每个状态–动作对 $(s,a)$ 被无限次访问；
  • 学习率满足 Robbins–Monro 条件：
$$\sum_{t=1}^{\infty}\alpha_t=\infty,\qquad \sum_{t=1}^{\infty}\alpha_t^{2}<\infty$$

其理论依据仍是贝尔曼最优算子的 $\gamma$-压缩性，结合随机逼近收敛定理。

四、四个经典建模案例

案例 1：迷宫寻路

智能体在未知迷宫中试错，学习各格子–方向的价值，逐步形成通往出口的贪心策略。

案例 2：多臂老虎机

多台拉杆收益未知，在试拉中估计各臂期望收益，平衡探索新臂与拉动已知最优臂。

案例 3：游戏智能体

以游戏画面 / 局面为状态、操作为动作、得分为奖励，Q 表或其深度逼近版本评价动作优劣。

案例 4：在线广告与推荐

把用户状态作为环境、出价 / 推荐作为动作，在线反馈作为奖励，在持续交互中调整决策。

五、具体算法：Q-learning 主循环

算法 1：ε-贪心动作选择

  1. 以概率 $\varepsilon$ 均匀随机选动作；
  2. 以概率 $1-\varepsilon$ 选 $\arg\max_a Q(s,a)$；
  3. 随训练推进可逐渐减小 $\varepsilon$，由探索转向利用。

算法 2：单步 Q 更新

$$Q(s,a)\leftarrow Q(s,a)+\alpha\big[r+\gamma\max_{a'}Q(s',a')-Q(s,a)\big]$$

若 $s'$ 为终止状态，目标项取 $r$，不再加后续价值。

算法 3：回合主循环

  1. 初始化 $Q(s,a)=0$；
  2. 每个回合重置到初始状态；
  3. ε-贪心选动作、执行转移、记录奖励、更新 $Q$；
  4. 到达终止或步数上限后开始下一回合。

算法 4：收敛与策略提取

Q 表收敛后，最优策略由贪心动作给出：

$$\pi^{*}(s)=\arg\max_a Q^{*}(s,a)$$

可用回合回报趋于稳定作为经验停机判据。

八、易理解的交互例子：多臂老虎机与探索–利用权衡

Bandit · 样本均值估计

三台拉杆，只知道收益、不知道哪台最好

三台拉杆各自按隐藏概率给出 0 或 1 的收益。每拉一次，用样本均值更新对该臂期望收益的估计：$\hat\mu_k\leftarrow\hat\mu_k+\frac{1}{n_k}(r-\hat\mu_k)$。选择不同策略，观察“只拉当前估计最好的臂（利用）”与“偶尔尝试其他臂（探索）”对累计收益的影响。

累计收益：0.00；已拉：0 次。先各拉几次建立初步估计，再切换不同策略对比长期表现。

九、可交互的应用案例：广告位在线择优（Bandit 推荐）

在线推荐 · 点击率估计

八、强化学习在人工智能中的应用

8.1 游戏智能体与深度 Q 网络

Q-learning 及其深度扩展（如 DQN）通过与游戏环境交互学习动作价值，是 Atari 等视频游戏 AI 的基础思想；离策略特性使其可复用历史经验与经验回放。

8.2 机器人交互学习

在难以建立精确动力学模型的场景中，机器人通过试错学习抓取、移动等策略，用 Q 表或函数逼近版本评价状态–动作。

8.3 在线推荐与广告出价

把用户状态作为环境、推荐 / 出价作为动作，在线反馈作为奖励，用无模型方法在持续交互中调整决策策略。

8.4 与后续部分可观测问题的衔接

本讲假设状态可被直接观测；当状态只能通过带噪观测推断时，决策需在信念状态上进行，这是第四讲 POMDP 讨论的内容。

练习 1：一步 Q 更新（手算）

已知 $Q(s,a)=1.2$，$r=1$，$\gamma=0.9$，$\max_{a'}Q(s',a')=0.8$，$\alpha=0.5$。求更新后的 $Q(s,a)$ 与 TD 误差。

查看解答过程

$$\delta=1+0.9\times0.8-1.2=0.52$$

$$Q(s,a)\leftarrow1.2+0.5\times0.52=1.46$$

练习 2：离策略含义（概念）

为什么说 Q-learning 是离策略算法？它与 SARSA 在更新目标上的关键区别是什么？这一区别对学到策略的保守程度有何影响？

参考要点

Q-learning 行为策略用于采样（ε-贪心），目标策略是贪心策略，更新目标取 $\max_{a'}Q(s',a')$；SARSA 按实际采取的下一动作 $a'$ 取值，属在策略。因此 Q-learning 倾向学到最优（可能更冒险）的策略，SARSA 会考虑探索本身的风险，策略相对保守。

练习 3：Q-learning 主循环（进阶 · 编程）

对 $3\times3$ 网格世界补全 Q-learning 主循环：初始化 Q 表，按 ε-贪心选动作、执行转移、按更新式修正 Q，直到回合结束。

for episode in range(EPISODES):
    s = reset()
    while not done:
        a = epsilon_greedy(Q, s, eps)
        s2, r, done = env.step(a)
        target = r if done else r + gamma * max(Q[s2])
        Q[s][a] += alpha * (target - Q[s][a])
        s = s2
查看解答过程

终止状态不再叠加后续价值；α 随训练逐步衰减可满足 Robbins–Monro 条件。运行足够多回合后，Q 表逼近 $Q^{*}$，由 $\arg\max_a Q(s,a)$ 提取贪心策略，可对照演示 2 的路径校验。

练习 4：收敛条件讨论（推导）

为什么要求每个 $(s,a)$ 被无限次访问？若某动作从未被尝试，Q-learning 能否发现它可能是最优的？学习率不满足 Robbins–Monro 条件会出现什么问题？

参考要点

未被访问的动作其 Q 值保持初值，无法被正确评价，算法可能遗漏最优动作。若 $\sum\alpha_t=\infty$ 不成立，估计值无法充分收敛到真值；若 $\sum\alpha_t^2=\infty$，随机波动可能使估计无法稳定。两个条件共同保证随机逼近依概率收敛。

练习 5：样本均值在线更新（手算题 · 老虎机）

某台拉杆前两次收益为 $r_1=1,\ r_2=0$，第三次收益 $r_3=1$。用增量式均值公式 $\hat\mu\leftarrow\hat\mu+\frac{1}{n}(r-\hat\mu)$，依次计算第二次结束与第三次结束后的样本均值。

查看解答过程

第一次后：$\hat\mu_1=1$，$n_1=1$。

第二次后：$\hat\mu_2=1+\frac{1}{2}(0-1)=0.5$，$n_2=2$。

第三次后：$\hat\mu_3=0.5+\frac{1}{3}(1-0.5)=0.5+\frac{0.5}{3}\approx0.667$。

这正是 Q 表更新 $\alpha=1/n$ 时的蒙特科夫均值估计：每来一个新样本，只按 $1/n$ 的比例把估计向新样本靠拢，样本越多估计越稳定。

练习 6：ε-贪心的动作概率（手算题）

状态 $s$ 下有 3 个动作 $a_1,a_2,a_3$，当前估计 $Q(s,a_1)=0.8$（最高），$Q(s,a_2)=0.3$，$Q(s,a_3)=0.5$，探索率 $\varepsilon=0.2$。求 ε-贪心策略下每个动作被选中的概率。

查看解答过程

最优动作为 $a_1$。按 ε-贪心公式：

$$\Pr(a_1)=1-\varepsilon+\frac{\varepsilon}{|\mathcal A|}=0.8+\frac{0.2}{3}\approx0.867$$

$$\Pr(a_2)=\Pr(a_3)=\frac{\varepsilon}{|\mathcal A|}=\frac{0.2}{3}\approx0.067$$

校验：$0.867+0.067+0.067\approx1$。可见即使 $a_2$ 价值最低，仍保留 $\varepsilon/3$ 的被选概率，用于探索其他动作；$\varepsilon$ 越大探索越强、利用越弱。

练习 7：实现一个 ε-贪心多臂老虎机（编程）

设定 3 台臂，真实收益期望分别为 0.3、0.7、0.5（伯努利抽样）。实现 ε-贪心策略：维护各臂计数与样本均值，每轮以 $\varepsilon$ 随机选臂、否则选当前均值最高的臂，运行 1000 轮，画出累计奖励曲线，并与纯贪心、纯随机对比。

查看解答过程
import numpy as np
means = [0.3, 0.7, 0.5]; eps = 0.2
counts = np.zeros(3); est = np.zeros(3); reward = 0; history = []
for t in range(1000):
    if np.random.rand() < eps:
        a = np.random.randint(3)
    else:
        a = int(np.argmax(est))
    r = 1 if np.random.rand() < means[a] else 0
    counts[a] += 1
    est[a] += (r - est[a]) / counts[a]
    reward += r; history.append(reward / (t + 1))

纯贪心在前期样本少时容易锁定次优臂，累计平均收益偏低；纯随机利用不足；ε-贪心在探索若干臂后逐步转向最优臂，长期平均收益最接近真实最优 0.7。可在演示 3 中切换三种策略直观对照。
