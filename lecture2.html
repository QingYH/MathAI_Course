马尔可夫决策过程（MDP）与动态规划

在第一讲随机过程的基础上引入动作与奖励，把决策问题形式化为 MDP；建立价值函数与贝尔曼方程，并在环境模型已知的前提下，用策略迭代与值迭代等动态规划方法求解最优策略。

一、课程导入：从“状态演化”到“主动决策”

例子 1：机器人在网格中选择走哪一格

第一讲的马尔科夫链中，状态是被动演化的。现在机器人可以主动选择动作：向上、下、左、右移动。不同动作导致不同的后继状态分布，也带来不同奖励（靠近目标得正奖励，撞入陷阱得负奖励）。决策的目标是：选择一套动作规则，使长期累积奖励最大。

例子 2：棋类中选择一步棋

棋局是状态，落子是动作，胜负与局面优势是奖励。棋手（或 AI）需要评估“在当前局面下，每种走法长期来看价值多大”，再选择价值最高的走法。这正是 MDP 中价值函数与最优策略要回答的问题。

与马尔科夫链的区别：MDP 在状态转移之外增加了动作与奖励，转移概率写成 $P(s'\mid s,a)$——下一状态不仅依赖当前状态，还依赖所选动作。

三、数学原理

3.1 MDP 五元组

一个有限马尔可夫决策过程由五元组描述：

$$\mathcal{M}=\langle \mathcal{S},\ \mathcal{A},\ P(s'\mid s,a),\ R(s,a),\ \gamma\rangle$$
  • $P(s'\mid s,a)=\Pr(S_{t+1}=s'\mid S_t=s,A_t=a)$：受控状态转移；
  • $R(s,a)=\mathbb{E}[R_{t+1}\mid S_t=s,A_t=a]$：即时奖励；
  • $\gamma\in[0,1]$：折扣因子，权衡长期与短期收益。

3.2 策略与折扣回报

策略 $\pi(a\mid s)$ 是状态到动作概率分布的映射：

$$\pi(a\mid s)=\Pr(A_t=a\mid S_t=s),\qquad \sum_{a\in\mathcal{A}}\pi(a\mid s)=1$$

从时刻 $t$ 出发的折扣回报为：

$$G_t=R_{t+1}+\gamma R_{t+2}+\gamma^{2}R_{t+3}+\cdots=\sum_{k=0}^{\infty}\gamma^{k}R_{t+k+1}$$

3.3 价值函数与贝尔曼期望方程

状态价值与动作价值定义为：

$$V^{\pi}(s)=\mathbb{E}_{\pi}[G_t\mid S_t=s],\qquad Q^{\pi}(s,a)=\mathbb{E}_{\pi}[G_t\mid S_t=s,A_t=a]$$

价值可按后继状态递归分解，得到贝尔曼期望方程：

$$V^{\pi}(s)=\sum_a\pi(a\mid s)\left[R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V^{\pi}(s')\right]$$
$$Q^{\pi}(s,a)=R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V^{\pi}(s')$$

3.4 贝尔曼最优方程

对每个状态取动作上确界，得到最优价值满足的贝尔曼最优方程：

$$V^{*}(s)=\max_{a\in\mathcal{A}}\left[R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V^{*}(s')\right]$$
$$Q^{*}(s,a)=R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V^{*}(s'),\qquad \pi^{*}(s)=\arg\max_a Q^{*}(s,a)$$
期望方程对应某一给定策略 $\pi$，是线性方程；最优方程含 $\max$ 算子，是非线性方程，需迭代逼近。

3.5 收敛性：压缩映射（γ-收缩）

定义贝尔曼最优算子 $\mathcal{T}$：

$$(\mathcal{T}V)(s)=\max_a\left[R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V(s')\right]$$

当 $\gamma<1$ 时，$\mathcal{T}$ 关于无穷范数是 $\gamma$-压缩映射：

$$\|\mathcal{T}V-\mathcal{T}V'\|_{\infty}\le\gamma\,\|V-V'\|_{\infty}$$

由压缩映射定理（巴拿赫不动点定理），迭代 $V_{k+1}=\mathcal{T}V_k$ 必收敛到唯一不动点 $V^{*}$，并有误差界：

$$\|V_k-V^{*}\|_{\infty}\le\frac{\gamma^{k}}{1-\gamma}\|V_1-V_0\|_{\infty}$$

四、四个经典建模案例

案例 1：栅格导航

状态为机器人栅格位置，动作为四向移动，目标得正奖励、陷阱得负奖励，求到达目标的最短最优路径。

案例 2：棋类与游戏 AI

局面为状态，合法走法为动作，胜负与局面评分为奖励，价值函数估计每种走法的长期优劣。

案例 3：库存管理

库存水平为状态，补货量为动作，持有成本与缺货惩罚构成奖励，求长期成本最小的订货策略。

案例 4：调度与排队

队列负载为状态，派单 / 调度为动作，服务水平与等待成本为奖励，建模为 MDP 求最优调度规则。

案例 5：外卖骑手派单决策

以骑手当前位置、负载与超时风险为状态，选择接哪一单、走哪条路线为动作，奖励由准时率、配送距离与顾客评分构成。平台在模型可估计时可用动态规划求出长期收益最优的派单规则；当路况与需求难以精确建模时，则过渡到第三讲的无模型强化学习。

五、具体算法（模型已知下的动态规划）

算法 1：策略评估

给定策略 $\pi$，按贝尔曼期望方程迭代求解 $V^{\pi}$：

$$V_{k+1}(s)=\sum_a\pi(a\mid s)\left[R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V_k(s')\right]$$

直至 $\max_s|V_{k+1}(s)-V_k(s)|<\theta$。

算法 2：策略改进

依据当前价值对每个状态取贪心动作，构造更优策略：

$$\pi'(s)=\arg\max_a Q^{\pi}(s,a)$$

若 $\pi'=\pi$，策略已最优；否则返回评估步骤。

算法 3：策略迭代

  1. 初始化策略 $\pi_0$；
  2. 策略评估求得 $V^{\pi_k}$；
  3. 策略改进得到 $\pi_{k+1}$；
  4. 策略稳定则停止，否则返回第 2 步。

算法 4：值迭代

把改进中的 $\max$ 并入价值更新，省略显式策略：

$$V_{k+1}(s)=\max_a\left[R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V_k(s')\right]$$

收敛后由 $V^{*}$ 导出最优策略 $\pi^{*}$。

十、MDP 与动态规划在人工智能中的应用

8.1 机器人导航与控制

把机器人位姿、任务进度建模为状态，移动 / 操作为动作，碰撞与目标达成为奖励。模型已知时可用值迭代 / 策略迭代求出最优导航策略，上层对接感知与定位模块。

8.2 博弈与游戏 AI

在状态转移可建模的棋类与决策游戏中，动态规划思想用于局面价值评估与最优动作选择，与极小化极大搜索、剪枝结合，构成早期游戏 AI 的决策核心。

8.3 库存与资源调度

库存、能源、交通调度等序贯决策问题建模为 MDP，状态为库存 / 负载水平，动作为补货 / 派单，用策略迭代或值迭代求长期成本最小的决策规则。

8.4 作为后续算法的基准

动态规划要求已知完整模型；当模型未知时，第三讲的无模型方法（Q-learning）以样本期望替代模型求和，其收敛性仍以贝尔曼最优算子的压缩性为理论基础。

十一、课堂练习（含详解）

练习 1–3、5–6 为课堂手算 / 推导，练习 4、7 可在 30 分钟内用 Python 完成。每道题都附有可折叠的详细解答过程。

练习 1：期望即时奖励（手算）

状态 $s$ 执行动作 $a$：以 0.6 概率转移到 $s_1$（奖励 $+1$），以 0.4 概率转移到 $s_2$（奖励 $-1$）。求 $R(s,a)$。

查看解答过程

$$R(s,a)=0.6\times1+0.4\times(-1)=0.2$$

练习 2：折扣回报（手算）

奖励序列 $R_{t+1}=2,\ R_{t+2}=0,\ R_{t+3}=4$，$\gamma=0.5$，计算 $G_t$。

查看解答过程

$$G_t=2+0.5\times0+0.5^{2}\times4=2+1=3$$

练习 3：两状态贝尔曼方程（推导）

两状态 $s_1,s_2$，$\gamma=0.8$，策略下 $R(s_1)=2,\ R(s_2)=1$，$P(s_2\mid s_1)=1,\ P(s_1\mid s_2)=1$。写出 $V^{\pi}$ 的方程并求解。

查看解答过程

$$V(s_1)=2+\gamma V(s_2),\qquad V(s_2)=1+\gamma V(s_1)$$

代入 $\gamma=0.8$：$V(s_1)=2+0.8(1+0.8V(s_1))$，解得 $V(s_1)\approx7.78$，$V(s_2)\approx7.22$。

练习 4：小型网格世界值迭代（挑战 · 编程）

自行实现 4×4 网格世界：定义障碍、目标与奖励，按贝尔曼最优方程迭代更新 $V(s)$，直到 $\max_s|V_{k+1}(s)-V_k(s)|<10^{-3}$，并提取贪心策略，可对照演示 2 校验。

def value_iteration(S, A, P, R, gamma=0.9, theta=1e-3):
    V = {s: 0.0 for s in S}
    while True:
        delta = 0
        for s in S:
            v = V[s]
            V[s] = max(R(s, a) + gamma * sum(P(s2 | s, a) * V[s2] for s2 in S)
                       for a in A(s))
            delta = max(delta, abs(v - V[s]))
        if delta < theta:
            break
    pi = {s: max(A(s), key=lambda a: R(s, a) + gamma * sum(P(s2 | s, a) * V[s2] for s2 in S))
          for s in S}
    return V, pi
查看解答过程

每轮对所有非终止状态执行贝尔曼最优更新。收敛后目标格价值最高、陷阱附近为负，贪心箭头一致指向目标方向。以演示 2 参数（$\gamma=0.9$，步长奖励 $-0.04$）运行约 20–30 轮收敛，可用相邻两轮价值最大差作为停机判据。

练习 5：手算动作价值并选最优动作（手算题）

沿用演示 3 的设定：$\gamma=0.9$。动作 $a_1$：$R=1$，以 0.7 到 $s_A$（$V=3$）、0.3 到 $s_B$（$V=1$）；动作 $a_2$：$R=2$，以 0.5 到 $s_A$（$V=3$）、0.5 到 $s_C$（$V=0$）。分别计算 $Q(s,a_1)$、$Q(s,a_2)$，并指出贪心策略应选哪个动作。

查看解答过程

动作 $a_1$：期望后继价值 $=0.7\times3+0.3\times1=2.40$；

$$Q(s,a_1)=1+0.9\times2.40=1+2.16=3.16$$

动作 $a_2$：期望后继价值 $=0.5\times3+0.5\times0=1.50$；

$$Q(s,a_2)=2+0.9\times1.50=2+1.35=3.35$$

比较 $3.35>3.16$，故贪心策略 $\pi^{*}(s)=\arg\max_a Q(s,a)$ 应选择 $a_2$。注意 $a_2$ 虽然后继期望价值更低，但即时奖励更高，在当前 $\gamma$ 下总分仍占优；若调小 $\gamma$，长期价值被压缩，结论可能改变，可在演示 3 中拖动 $\gamma$ 验证。

练习 6：策略评估的一轮迭代（手算题）

两状态 $s_1,s_2$，$\gamma=0.8$。固定策略下：$R(s_1)=2,\ R(s_2)=1$；$P(s_2\mid s_1)=1,\ P(s_1\mid s_2)=1$。上一轮价值估计 $V_k(s_1)=0,\ V_k(s_2)=0$。按贝尔曼期望方程计算一轮更新后的 $V_{k+1}(s_1),V_{k+1}(s_2)$，并再迭代一轮观察数值变化。

查看解答过程

贝尔曼期望更新：$V_{k+1}(s)=R(s)+\gamma\sum_{s'}P(s'\mid s)V_k(s')$。

第一轮（$V_k=0$）：

$$V_{k+1}(s_1)=2+0.8\times V_k(s_2)=2+0=2.00$$

$$V_{k+1}(s_2)=1+0.8\times V_k(s_1)=1+0=1.00$$

第二轮（用上一步结果）：

$$V_{k+2}(s_1)=2+0.8\times1.00=2.80$$

$$V_{k+2}(s_2)=1+0.8\times2.00=2.60$$

继续迭代将收敛到练习 3 的解析解 $V(s_1)\approx7.78,\ V(s_2)\approx7.22$。每一轮都把后继状态的价值按 $\gamma$ 折现并叠加即时奖励，这正是策略评估的备份过程。

练习 7：库存策略的成本权衡（概念 + 编程）

在演示 4 的库存模型中，分别实现“不补货”“每日补 1 件”“补到 3 件”三种策略，各模拟 1000 天，统计平均每日成本、平均缺货件数与平均库存，说明三者的成本结构差异，并猜测最优策略大致处于什么区间。

查看解答过程

不补货：库存很快耗尽，缺货惩罚占主导，长期成本高；补到 3 件：缺货最少，但期末库存高，持有成本上升；每日补 1 件：在两者之间。需求期望为 $0.3\times0+0.5\times1+0.2\times2=0.9$ 件/天，因此长期补货量需接近期望需求才能平衡缺货与持有。最优订货点 / 订货量应由 MDP 求解得到，通常是一个“库存低于阈值就补货”的阈值策略，而不是固定每天补同样数量。

练习 8：单状态循环的折扣回报（手算题）

仅有一个状态 $s$，执行动作后确定性地留在 $s$，每步获得相同即时奖励 $r=3$，折扣因子 $\gamma=0.9$。(1) 写出该状态价值满足的贝尔曼方程；(2) 解析求解 $V(s)$；(3) 说明当 $\gamma\to1$ 时 $V(s)$ 的变化及其含义。

查看解答过程

(1) 贝尔曼方程：状态不转移，后继仍是自身，故

$$V(s)=r+\gamma V(s)=3+0.9V(s)$$

(2) 求解：移项得 $(1-\gamma)V(s)=r$，因此

$$V(s)=\frac{r}{1-\gamma}=\frac{3}{1-0.9}=30$$

也可由折扣回报级数直接验证：$V=3+3\gamma+3\gamma^{2}+\cdots=\frac{3}{1-\gamma}=30$。

(3) 极限含义：当 $\gamma\to1$ 时 $\frac{r}{1-\gamma}\to\infty$，即不打折时无限步恒定奖励的累积回报发散。这正是折扣因子要求 $\gamma<1$ 的原因：它既保证级数收敛，也使压缩映射的收缩系数 $\gamma<1$，从而价值迭代存在唯一不动点；$\gamma$ 越接近 1，智能体越看重远期回报，但收敛也越慢。

思考题：策略迭代每轮要做完整策略评估，值迭代把评估与改进合并。在状态空间很大时，为什么值迭代往往更易实现？两者各自的收敛代价如何？
