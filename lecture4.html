部分可观测决策与 POMDP

真实智能体往往只能获得带噪、不完全的观测。本讲先以隐马尔可夫模型（HMM）建立观测与推断的概率基础，再引入信念状态与贝叶斯更新，把决策建立在对隐藏状态的概率推断之上，讨论信念 MDP 的求解难度与近似方法。

一、课程导入：看不见完整状态时如何决策

例子 1：医生根据症状判断病情

真实病情（隐状态）无法直接看到，医生只能观察到体温、化验指标等带噪观测。每获得一项检查结果，就更新一次对各种病情可能性的判断，再据此选择治疗方案。决策依据不是某个确定状态，而是一组状态概率。

例子 2：机器人在走廊里估算自身位置

机器人不知道自己确切在哪一格，只能通过里程计（带噪声的运动）与传感器读数（带噪声的观测）不断修正位置置信度。运动后先预测位置分布，看到路标后再用观测修正——这正是滤波与信念更新的微型版本。

前三讲假设智能体可直接观察真实状态；本讲面对部分可观测情形：状态隐藏，决策建立在信念（状态概率分布）之上。

三、数学原理

3.1 概念关系：链、HMM、MDP、POMDP

  • 马尔可夫链：自发转移的随机过程；
  • 隐马尔可夫模型（HMM）：隐状态链满足马尔科夫性，每个隐状态按发射概率产生观测；
  • MDP：转移受动作控制，但状态可直接观测；
  • POMDP：在 MDP 基础上状态不可直接观测，只能得到带噪观测。

退化关系：观测无噪声时 POMDP 退化为 MDP；去掉动作控制则退化为 HMM。

3.2 HMM 三个基本问题

  1. 评估问题：给定模型 $\lambda=(A,B,\pi)$，计算观测序列概率 $P(O\mid\lambda)$ —— 前向 / 后向算法；
  2. 解码问题：求最可能的隐状态序列 —— Viterbi 算法；
  3. 学习问题：从数据估计模型参数 —— Baum–Welch 算法（EM 的一种）。

3.3 前向概率与前向算法

定义前向概率 $\alpha_t(i)=P(o_1,\dots,o_t,q_t=i\mid\lambda)$，递推为：

$$\alpha_1(i)=\pi_i B_i(o_1)$$
$$\alpha_t(j)=B_j(o_t)\sum_i\alpha_{t-1}(i)a_{ij}$$

观测序列概率为 $P(O\mid\lambda)=\sum_i\alpha_T(i)$。

3.4 Viterbi 解码

每一步保留到达各隐状态的最大概率 $\delta_t(j)$，并用指针 $\psi_t(j)$ 记录来源：

$$\delta_t(j)=B_j(o_t)\max_i\big[\delta_{t-1}(i)a_{ij}\big],\qquad \psi_t(j)=\arg\max_i\delta_{t-1}(i)a_{ij}$$

最后从 $\delta_T$ 最大的状态出发，沿 $\psi$ 指针回溯，得到最可能的隐状态路径。

3.5 POMDP 七元组与信念状态

POMDP 在 MDP 基础上增加观测集与观测函数：

$$\mathcal{P}=\langle\mathcal{S},\mathcal{A},\mathcal{O},Z(o\mid s',a),T(s'\mid s,a),R(s,a),\gamma\rangle$$

由于真实状态不可获知，智能体维护关于状态的概率分布——信念状态：

$$b(s)=\Pr(S_t=s\mid O_{1:t},A_{0:t-1})$$

信念是历史观测与动作的充分统计量，有了信念便不必保留完整历史。

3.6 信念更新：预测步与观测步

执行动作 $a$ 后先做预测步：

$$\tilde b(s')=\sum_{s\in\mathcal{S}}T(s'\mid s,a)\,b(s)$$

获得观测 $o$ 后做观测步（贝叶斯修正并归一化）：

$$b'(s')=\frac{Z(o\mid s',a)\,\tilde b(s')}{\Pr(o\mid b,a)},\qquad \Pr(o\mid b,a)=\sum_{s'}Z(o\mid s',a)\,\tilde b(s')$$

3.7 信念 MDP 与求解难度

把信念 $b$ 视为新状态，得到连续状态的信念 MDP，价值定义在信念单纯形上：

$$V(b)=\max_a\left[\sum_s b(s)R(s,a)+\gamma\sum_o\Pr(o\mid b,a)V(b')\right]$$
  • 有限状态 POMDP 的最优价值函数是分段线性且凸（PWLC）的；
  • 信念空间随状态数指数增长，精确求解一般为 PSPACE 难；
  • 近似途径：点值迭代（PBVI）、蒙特卡洛规划、在线重规划，以及用循环 / Transformer 网络压缩历史的深度方法。

四、四个经典建模案例

案例 1：由“是否带伞”推断天气

隐状态为晴 / 雨，观测为带伞 / 不带伞，用前向算法计算观测序列概率，用 Viterbi 反推最可能天气路径。

案例 2：移动机器人定位

位置不可精确获知，运动模型做预测、传感器读数做修正，信念分布随滤波不断收敛到真实位置附近。

案例 3：医疗诊断决策

病理状态隐藏，检查结果是带噪观测；在病情信念上安排检查与治疗，平衡信息获取、疗效与成本。

案例 4：对话状态跟踪

用户意图是隐状态，语音识别与文本是观测；系统维护意图信念并据此选择回复动作，是对话管理的常见建模方式。

五、具体算法

算法 1：前向算法（评估）

  1. 初始化 $\alpha_1(i)=\pi_i B_i(o_1)$；
  2. 递推 $\alpha_t(j)=B_j(o_t)\sum_i\alpha_{t-1}(i)a_{ij}$；
  3. 求和得 $P(O\mid\lambda)=\sum_i\alpha_T(i)$。

算法 2：Viterbi 解码

  1. 初始化 $\delta_1(i)=\pi_i B_i(o_1)$；
  2. 递推 $\delta_t(j)$ 并记录指针 $\psi_t(j)$；
  3. 从终点最大 $\delta_T$ 沿指针回溯最优路径。

算法 3：信念滤波更新

  1. 预测：$\tilde b(s')=\sum_s T(s'\mid s,a)b(s)$；
  2. 观测：$b'(s')\propto Z(o\mid s',a)\tilde b(s')$；
  3. 归一化后作为下一步信念。

算法 4：近似求解（概览）

信念空间过大时，用点值迭代在代表性信念点上维护价值片段，或用蒙特卡洛在线规划采样候选动作；深度方法则用循环网络把历史压缩为隐状态。

十、部分可观测方法在人工智能中的应用

10.1 语音识别与词性标注

声学信号 / 词语是观测，音素 / 词性是隐状态；HMM 前向与 Viterbi 是早期语音识别与序列标注的核心算法。

10.2 医疗诊断决策

病情为隐状态，检查结果为观测；POMDP 框架用于安排检查与治疗，平衡信息获取、疗效与成本。

10.3 对话状态跟踪

用户意图为隐状态，识别文本为观测；系统维护意图信念并选择回复动作，是任务型对话管理的常见建模。

10.4 金融与生物序列

市场状态、基因结构等不可直接观测，常用 HMM 刻画隐状态转移与观测生成，做状态识别与异常检测。

十一、课堂练习（含详解）

练习 1、2、5、6 为课堂手算 / 推导，练习 4、7 可在 30 分钟内用 Python 完成，练习 3 为概念讨论。每道题都附有可折叠的详细解答过程。

练习 1：前向概率手算（手算）

沿用演示 1 参数，观测 $O=(\text{带伞},\text{不带伞},\text{带伞})$。手算第一步 $\alpha_1$，并说明 $P(O\mid\lambda)$ 如何由 $\alpha_3$ 求和得到。

查看解答过程

第 1 步（观测“带伞”）：$\alpha_1=(0.6\times0.2,\;0.4\times0.9)=(0.1200,\;0.3600)$。继续递推可得 $\alpha_3=(0.027552,\;0.062856)$，故 $P(O\mid\lambda)=0.090408$。

练习 2：信念更新计算（手算）

设 $b(A)=0.6,\ b(B)=0.4$；动作 $a_1$ 下 $T(A\mid A)=0.7,\ T(B\mid A)=0.3,\ T(A\mid B)=0.3,\ T(B\mid B)=0.7$；观测 $o_1$ 似然 $Z(o_1\mid A)=0.8,\ Z(o_1\mid B)=0.3$。求预测信念与收到 $o_1$ 后的后验信念。

查看解答过程

预测：$\tilde b(A)=0.6\times0.7+0.4\times0.3=0.54$，$\tilde b(B)=0.46$。似然加权：$0.54\times0.8=0.432$，$0.46\times0.3=0.138$，归一化常数 $0.570$。后验：$b'(A)\approx0.758$，$b'(B)\approx0.242$。

练习 3：Viterbi 路径（对照演示）

观察演示 2 的 $\delta$ 与 $\psi$ 表，说明回溯顺序：为什么要从最后一步最大 $\delta_T$ 的状态出发，而不是从第一步开始正向选最大？

参考要点

Viterbi 求的是整条路径的联合概率最大，局部最优不等于全局最优。$\delta_t(j)$ 已汇总到达 $j$ 的最优前缀，$\psi$ 记录其来源；只有从终点最优状态反向回溯，才能还原出全局最优的完整隐状态序列。

练习 4：信念 MDP 编程框架（进阶 · 编程）

对两状态 POMDP 实现信念更新函数：输入当前信念、动作、观测与 $T,Z$ 矩阵，输出归一化后验信念。

def belief_update(b, a, o, T, Z):
    tilde = [sum(T[s2][s][a] * b[s] for s in range(len(b)))
             for s2 in range(len(b))]
    weighted = [Z[s2][o][a] * tilde[s2] for s2 in range(len(b))]
    norm = sum(weighted)
    return [w / norm for w in weighted]
查看解答过程

先按转移核做预测（先验），再用观测似然加权，最后除以边际似然 $\Pr(o\mid b,a)$ 归一化。可代入演示 4 的数值，与页面结果互相校验。

练习 5：单次观测的贝叶斯后验（手算题）

设先验 $P(\text{感冒})=0.6$，$P(\text{过敏})=0.4$。观测到“发烧”，似然 $Z(\text{发烧}\mid\text{感冒})=0.8$，$Z(\text{发烧}\mid\text{过敏})=0.2$。求发烧后两种疾病的后验概率。

查看解答过程

似然加权（未归一化）：

$$\tilde b(\text{感冒})=0.6\times0.8=0.48,\qquad \tilde b(\text{过敏})=0.4\times0.2=0.08$$

归一化常数 $\Pr(\text{发烧})=0.48+0.08=0.56$，故

$$b'(\text{感冒})=\frac{0.48}{0.56}\approx0.857,\qquad b'(\text{过敏})=\frac{0.08}{0.56}\approx0.143$$

发烧这一证据把信念明显推向“感冒”。注意后验 = 先验 × 似然，再除以证据的边际概率。

练习 6：连续两条证据的信念更新（手算题）

沿用练习 5：发烧后信念为 $b(\text{感冒})\approx0.857,\ b(\text{过敏})\approx0.143$。随后又观测到“打喷嚏”，似然 $Z(\text{打喷嚏}\mid\text{感冒})=0.4$，$Z(\text{打喷嚏}\mid\text{过敏})=0.9$（假设两症状在给定疾病下条件独立）。求更新后的后验。

查看解答过程

以发烧后的后验作为新先验，再次似然加权：

$$\tilde b(\text{感冒})=0.857\times0.4\approx0.343,\qquad \tilde b(\text{过敏})=0.143\times0.9\approx0.129$$

归一化常数 $\approx0.343+0.129=0.472$，故

$$b''(\text{感冒})\approx\frac{0.343}{0.472}\approx0.727,\qquad b''(\text{过敏})\approx\frac{0.129}{0.472}\approx0.273$$

“打喷嚏”更符合过敏，把过敏后验从 0.143 拉回到 0.273，但感冒仍占优。多条证据按贝叶斯公式逐条累积，正是信念滤波的递推过程。

练习 7：三状态意图信念更新（编程）

对演示 6 的三意图模型，实现一个通用信念更新函数：输入当前信念向量、观测关键词对应的似然向量，输出归一化后验；再依次输入“机票”“退”两个关键词，打印每一步的意图信念。

def update(b, lik):
    w = [lik[i] * b[i] for i in range(len(b))]
    norm = sum(w)
    return [x / norm for x in w]

b = [1/3, 1/3, 1/3]
b = update(b, [0.7, 0.1, 0.2])   # “机票”
b = update(b, [0.1, 0.8, 0.1])   # “退”
print([round(x, 3) for x in b])
